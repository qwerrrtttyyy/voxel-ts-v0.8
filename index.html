关于

TypeScript + Vite + Three.js，零 UI 框架。核心只装配基础设施，全部游戏能力通过 服务令牌 / 事件总线 / 插件作用域提供。

  • 7 个内置插件提供兜底实现（低优先级），任何玩法插件都能以更高优先级顶替
  • 插件用 ctx.scope.* 注册一切，卸载自动释放，不写 dispose
  • 方块、贴图、二进制段、事件类型全部命名空间化，第三方不撞车
  • 世界体素是扁平 Uint8Array，渲染层消费 dirty 队列分帧重建
  • 跨插件数据只走 ArrayBuffer TLV 信封，未知段原样透传

v0.3 新增：运行时插件市场、主菜单、M2 挖放 / AABB / 物品栏、M4 昼夜与存档落盘。

v0.8 把深度审批做成一等插件：20 条类型化规则对当前运行时重新采样，覆盖插件契约、服务装配、二进制段、沙箱、性能与协议版本；第三方可追加规则，关掉插件即整体撤销。并用 TS 名义类型、const 泛型、satisfies、模板字面量与映射类型，把插件重名、权限写错、事件名乱起等错误前移到编译期。v0.7 用真 3D 密度场替代 2D 高度图：悬垂岩板、浮空岛、天然拱门、连续洞穴管道与立体矿脉都能生成，一列里可以出现「实心 → 空气 → 实心」；在插件仓库关掉「真 3D 地形」即可回退到旧地形。v0.6 加固与体验优化：运行时热加载插件进入受限沙箱、存档支持版本迁移与跨配置校验、依赖语义与生命周期事件补齐；准星射线单源、视角插值、WebGL 上下文自动恢复、昼夜曝光联动与入水遮罩。分区系统把世界按 16×16 chunk 划区，按玩家位置滑动加载窗口实现负坐标无限生成，改动自动归档、往返不丢；性能画像可在插件仓库里看到每个回调的耗时。v0.5 全量 Cordis 化让插件与世界组件共享同一个可逆内核，四条形式化定理覆盖整个插件生态。
